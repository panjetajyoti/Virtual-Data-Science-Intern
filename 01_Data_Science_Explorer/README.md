# Track 1: Virtual Data Science Explorer

This directory contains the strategic planning frameworks, universal exploratory data analysis (EDA) methodologies, and machine learning architecture designs developed during the 4-week Data Science Explorer apprenticeship.

---

## 📌 Weekly Deliverables & Focus Areas

* **Week 1: Data Science Project Planning & Strategy Design**
  - Formulation of enterprise logistics demand forecasting architectures.
  - 35-hour project lifecycle breakdown, risk matrix, and telemetry ingestion protocols.
  - Artifact: `Week1_Data_Science_Project_Planning_Strategy.docx`

* **Week 2: Universal EDA & Visualization Framework Design**
  - Universal taxonomy design for tabular data (Continuous, Discrete, Nominal, Ordinal, Temporal).
  - Outlier triage protocols using non-parametric Interquartile Range (IQR) boundaries.
  - Automated reusable Python framework: `scripts/generic_eda_framework.py`
  - Artifact: `Week2_Generic_EDA_Visualization_Framework.docx`

* **Week 3: Python ML Model Development & Evaluation Plan**
  - End-to-end supervised machine learning system design targeting customer churn and demand shocks.
  - Validation schemas comparing regularized linear baselines against LightGBM and Random Forests.
  - Artifact: `Week3_ML_Model_Development_Evaluation_Plan.docx`

* **Week 4: Comprehensive Insights & Strategic Presentation Plan**
  - Framework for translating quantitative outputs (PR-AUC, F1-scores) into C-suite operational strategies.
  - Artifact: `Week4_Comprehensive_Data_Science_Insights_Report.docx`
