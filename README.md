# Multi-Track Virtual Data Science Apprenticeship Portfolio

This repository consolidates the technical deliverables, statistical pipelines, and machine learning models developed across three specialized tracks under the **Virtual Data Science Apprenticeship** (July 2026 – September 2026).

---

## 📌 Completed Tracks Overview

### 1. [Virtual Data Science Explorer](01_Data_Science_Explorer/)
* Focused on foundational exploratory data analysis (EDA), anomaly identification, and pattern recognition across multi-dimensional datasets.
* Implemented standardized data quality audits and visual reporting frameworks.

### 2. [Virtual Data Science with R](02_Data_Science_with_R/)
* **Data Wrangling & Preprocessing:** Engineered reproducible pipelines using `tidyverse`, `lubridate`, and non-parametric IQR outlier mitigation.
* **Statistical Modeling & Elasticity:** Evaluated supply-price dynamics using Generalized Additive Models (GAM) and `ggplot2`.
* **Predictive Classification:** Built and benchmarked Random Forest classifiers in R (`caret`, `pROC`), achieving an ROC-AUC of 0.841.

### 3. [Virtual Data Science with Python](03_Data_Science_with_Python/)
* **Feature Engineering:** Developed leakage-free temporal features including 7-day rolling moving averages, price lags, and volatility spreads.
* **Supervised Machine Learning:** Trained and evaluated Random Forest and Logistic Regression models using `scikit-learn`.
* **Diagnostic Performance:** Achieved 76.8% directional accuracy and an ROC-AUC score of 0.835 for short-term price movement detection.
* **Executive Capstone:** Synthesized technical findings into strategic stakeholder recommendations for inventory buffering and supply chain optimization.

* **Languages:** Python 3.10+, R 4.3+

* **Techniques:** Missing Value Imputation, Outlier Mitigation, Walk-Forward Validation, Confusion Matrix Diagnostics, ROC-AUC Profiling
